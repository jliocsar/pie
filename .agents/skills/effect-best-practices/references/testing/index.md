# testing

Effect-aware testing helpers for Effect v4 via `@effect/vitest`.

- [`bun-test.md`](./bun-test.md) — running Effect tests under `bun:test`, where `it.effect` doesn't exist: a `ManagedRuntime` per file, platform fakes, `TestConsole`.
- [`vitest.md`](./vitest.md) — `it.effect`/`it.live`/`it.layer`/`layer()`, `TestClock` time control, `flakyTest`, and property testing with `prop`.
